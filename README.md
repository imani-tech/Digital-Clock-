# ⏰ Flipping Clock

A modern animated flipping clock built with HTML, CSS, and JavaScript.

## ✨ Features

- Smooth flip animations
- Real-time clock updates
- Responsive design
- Modern UI
- Lightweight and fast

## 🚀 Preview

Animated digital flipping clock interface inspired by retro flip clocks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/imani-tech/Digital-Clock-.git
```

Open the project folder:

```bash
cd Digital-Clock-
```

Then open `index.html` in your browser.
